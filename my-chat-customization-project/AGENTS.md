# AI Coding Agents Instructions

## Project Overview
This project is designed to facilitate the development and customization of AI coding agents. It provides a structured approach to ensure that agents can effectively interact with the codebase and adhere to established conventions.

## Project Structure
- **.github/prompts/agent-customization.prompt.md**: Contains prompts and instructions for customizing AI agents.
- **AGENTS.md**: Main instructions file for AI coding agents.
- **README.md**: Overview of the project, setup instructions, and relevant information for users or contributors.

## Coding Standards
- Follow consistent naming conventions for variables, functions, and classes.
- Maintain a clean and organized code structure.
- Write clear and concise comments where necessary to explain complex logic.

## Guidelines for Agents
1. **Understanding the Codebase**: Familiarize yourself with the project structure and key files. Use the README.md for initial guidance.
2. **Adhering to Conventions**: Follow the coding standards outlined above to ensure consistency across the codebase.
3. **Utilizing Prompts**: Refer to the prompts in `.github/prompts/agent-customization.prompt.md` for specific instructions on how to interact with the codebase effectively.

## Additional Resources
- For detailed customization instructions, refer to the prompts file.
- Consult the README.md for setup and contribution guidelines.

By following these instructions, AI coding agents will be better equipped to navigate and contribute to the project efficiently.
