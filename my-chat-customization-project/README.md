# My Chat Customization Project

**Author:** Kanwardeep Singh

## Overview
This project is designed to provide a framework for customizing AI agents that interact with a codebase. It includes specific instructions and prompts to ensure that the agents can effectively understand and navigate the project structure, adhere to coding standards, and follow established conventions.

## Purpose
The primary goal of this project is to enhance the productivity of AI coding agents by providing them with clear guidelines and customization options. This will help streamline the development process and improve the overall quality of the code produced.

## Project Structure
- **.github/prompts/agent-customization.prompt.md**: Contains prompts and instructions for customizing AI agents.
- **AGENTS.md**: Main instructions file for AI coding agents, detailing project structure and coding standards.
- **README.md**: Overview of the project, setup instructions, and relevant information for users or contributors.

## Setup Instructions
1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Follow the instructions in `AGENTS.md` to understand the coding standards and project structure.
4. Refer to `.github/prompts/agent-customization.prompt.md` for guidance on customizing AI agents.

## Contribution
Contributions are welcome! Please follow the guidelines outlined in `AGENTS.md` for contributing to this project. Ensure that any changes adhere to the coding standards and conventions established in the project.
